About the project

SwasthSathi 2.0 is a college-level AI/ML web application prototype.

Frontend

HTML5, CSS3, JavaScript and responsive components.

Backend

Python Flask with SQLite through SQLAlchemy.

Machine Learning

Random Forest with one-hot encoded categorical features.

Scope & limitation

The supplied dataset has only 349 records, 116 disease classes, four symptom fields and a few profile fields. Many classes have one or very few examples. Therefore this application should be presented as an educational prototype for demonstrating ML integration, not as a clinically validated diagnostic system.
